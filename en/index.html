FAQ

The short version

Does Arachnel include a game catalog?

No built-in catalog. Sources are connected through plugins: a plugin fills the Catalog and handles download, install and launch.

How does it work on Linux?

The launcher fetches Proton and whatever else it needs to run games, so you don't have to set the system up by hand.

Will every game run?

No. Games with DRM or anti-cheat may not work. It depends on the game and the source.

Where do I report bugs and ideas?

On GitHub Issues.

Can I help with translations?

Yes, translations live on Weblate.
